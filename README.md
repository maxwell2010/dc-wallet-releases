# DC Wallet Android

Официальные APK кошелька Decimal от MintCandy. Исходники хранятся в отдельном приватном репозитории.

## Скачать

[Последняя версия DC Wallet для Android](https://github.com/maxwell2010/dc-wallet-releases/releases/latest/download/DC-Wallet.apk)

[История выпусков](https://github.com/maxwell2010/dc-wallet-releases/releases)

Это приложение для Decimal Mainnet (75), с собственной release-подписью MintCandy. Подпись Google Play не используется. SHA256 APK и сертификата опубликованы в каждом выпуске.

## Переход с Preview

Release устанавливается рядом с Preview, без удаления его данных. Сохраните зашифрованную резервную копию и сид-фразу, импортируйте кошелек в новом приложении и проверьте доступ. Не удаляйте Preview до этой проверки. Никому не отправляйте сид-фразу, файл резервной копии или пароль.

Пакет: `ru.mintcandy.decimalwallet`. Версия: 0.3.0. Для установки скачанного APK Android может попросить разрешить установку из выбранного источника.
